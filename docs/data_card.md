# Data card: `data/sandbox.jsonl`

**What it is.** 2,044 labelled (state, action) rows from a simulated personal workspace (files, recycle bin, backups, version history, email drafts/outbox, bank account, savings). Every row has `environment = "sandbox"` and `source = "sandbox-generator-v1"`. No real files, mail or accounts are involved. ScienceWorld data is not part of this file.

**How it was generated.** Synthetically, by `reversibility/generate.py` (scenarios and minimal pairs), `reversibility/sandbox.py` (tool semantics as pure functions on a JSON state) and `reversibility/labeler.py` (labels). `python -m reversibility.generate --scenarios 265 --seed 0 --out <path>` reproduces the file byte for byte (checked 2026-11-20 into a scratch path). Each of the 265 scenarios (`sb-0000` to `sb-0264`) has one of 8 themes, one random base state, three paired tools sampled by weight, and one single tool.

**Labels.** For each row the labeler applies the action and runs a breadth-first search over restoring tool sequences of length ≤ h. The search sees only what an agent could observe after the action and only tries actions on entities that differ from the original state.
- `reversible`: some sequence of ≤ h calls restores the exact state (contents, versions, recycle bin, drafts, outbox, sent mail, balances, transfers).
- `partially_reversible`: no exact restore, but within h calls the user-visible content is back (versions may differ, extra items may stay in the bin, up to 3% of money may be lost).
- `irreversible`: neither.

`label` is the h = 3 label; `labels_by_horizon` holds h = 1, 2, 3 (168 rows change label across horizons). `restore_sequence` is the shortest exact sequence, else the shortest approximate one, else empty.

**Counts (h = 3).**

| | reversible | partially reversible | irreversible | total |
|---|---|---|---|---|
| all rows | 1,021 | 485 | 538 | 2,044 |
| minimal-pair rows | 808 | 455 | 516 | 1,779 (87%) |

85 rows are read-only actions (`list_files`, `read_file`, `view_trash`, `check_balance`), all reversible. 19 tools (`verb`) occur; 9 of them have rows with a single label only.

**Pair and group structure.** 1,060 groups (`group_id`, nested in `scenario_id`): 606 pairs, 189 triples (`edit_file`: backup / history / neither) and 265 singles. Within a group the action text is identical and one setting changes (recycle bin, send delay, scheduled transfers, savings fee, backups, version history, backed-up bin contents). `is_minimal_pair` is true when a group has more than one row and more than one distinct label. Splits in all analyses are grouped by `scenario_id`.

**Known quirk.** 10 `move_to_savings` rows with a 2% withdrawal fee are labelled `partially_reversible` with an empty `restore_sequence`: the 2% fee is within the 3% money tolerance, so the state counts as approximately restored after zero follow-up calls. They are kept as labelled.

**Limitations.** Labels come only from the programmatic search above. They were not independently annotated by people, and there is no inter-annotator agreement. States, file contents and names are synthetic templates, so lexical regularities from the generator can leak into features (see the post-hoc text baselines).

# Data card: `data/scienceworld.jsonl`

**What it is.** 512 labelled (state, action) rows from ScienceWorld 1.2.3 (`environment = "scienceworld"`, `source = "scienceworld-projected-bfs-v3"`), same schema as the sandbox rows plus `labels_by_horizon`, `group_id`, `pair_id`, `restore_depth` and the candidate observation. Tasks: freeze 208, boil 180, chemistry-mix 115, find-plant 9 rows (33 task variations = 33 groups). Generated by `scripts/run_scienceworld_slice.sh` (`scienceworld_slice/build_slice.py`): 1,113 raw labelled rows, then any class capped at 50% by dropping unpaired rows.

**How labels are computed.** States are rebuilt by reset and replay of the gold-path prefix. After the candidate action, a breadth-first search tries restoring sequences of ≤ 3 actions on the objects the action touched, and compares each node with a matched control of the same length (the same prefix followed by `wait1` steps), so world drift common to both branches does not count. Comparison uses a projection (agent room, inventory names, door states from `look()`, the touched objects and their containers): **reversible** when all discrete fields match and temperatures agree within 1 °C; **partially reversible** when discrete fields match but a temperature differs by more; **irreversible** otherwise. Actions with no effect are dropped. `label` is the h = 3 label.

**Counts.** 72 rows are exact duplicates (same state, action, label); the analyses use the 440 remaining rows (33 groups, 105 pairs).

| | reversible | partially reversible | irreversible |
|---|---|---|---|
| h = 1 (512 / 440 rows) | 241 / 214 | 207 / 171 | 64 / 55 |
| h = 2 | 254 / 223 | 207 / 171 | 51 / 46 |
| h = 3 | 256 / 225 | 205 / 169 | 51 / 46 |

249 of 512 rows (48.6%; 214 of 440 after deduplication) are in minimal pairs (same group and pair key, different labels); 19 rows (14 after deduplication) change label across horizons.

**Known weaknesses.**
- The partially reversible class is defined by temperature alone (discrete state restored, a temperature off by more than 1 °C), not by any lost content or cost.
- "Irreversible" means not restorable with ≤ 3 actions on the touched objects within the projection; actions on other objects or a longer plan might restore the state.
- Only about 10% of rows are irreversible (51 of 512, 46 of 440), mostly `pour` (21) and `mix` (13) after deduplication, so binary results rest on few irreversible groups and their CIs are wide.
- find-plant contributes only 9 rows.
- Near-duplicates remain after removing exact duplicates: 73 pairs of rows (134 rows) share a group and action and differ in at most two state lines; 36 of those pairs have the same label.
- With 33 groups, each test split has about 7 groups, and bootstrap resamples that draw no irreversible group give a constant predictor a balanced accuracy of 1.0; the upper ends of ScienceWorld balanced-accuracy CIs are therefore inflated (the majority-class CI is [0.50, 0.83] for binary).

# Human label check (both environments)

A blind sample of 100 items (50 per environment, about one third per label, 5 matched pairs per environment; `labeling/`) was labelled by **one annotator** following `labeling/guide.txt`; a second rater and the retest have not been collected. Agreement with the automatic labels (`results/analysis/human_agreement.json`, `experiments/label_agreement.py`): Cohen's kappa 0.26 [0.12, 0.40] overall, 0.25 [0.02, 0.47] sandbox, 0.28 [0.11, 0.45] ScienceWorld (three classes, 1,000-resample bootstrap). Post-hoc, on the 46 items where both labels are reversible or irreversible: kappa 0.68 [0.47, 0.87], agreement 0.85 [0.75, 0.94]. Most disagreement involves the partially reversible class; the annotator labelled 50 items reversible and 18 irreversible against 34 and 32 automatic. With a single annotator there is no inter-annotator agreement.
